## Personal account fields

Enter the maintainer's real information directly in SignPath. Do not copy
these values into the repository:

- **First Name:** maintainer's legal first name.
- **Last Name:** maintainer's legal last name.
- **Email:** an email account controlled by the maintainer and monitored for
  signing approvals and security notifications.
- **Company Name:** leave blank if applying as an individual.

## Discovery fields

Answer according to how the maintainer actually found SignPath. If the form
provides `Other`, an accurate response for this project is:

```text
AI assistant recommendation while researching Authenticode signing for an open-source Windows application.
```

For **Please specify the exact source**, use:

```text
OpenAI ChatGPT/Codex discussion about Microsoft SmartScreen and open-source code signing.
```

## Before submission

- Confirm that the maintainer owns or has permission to release all legal
  template text under Apache-2.0.
- Confirm that `SignPath Foundation` is acceptable as the Windows publisher.
- Enable multi-factor authentication on GitHub.
- Use only truthful adoption and download information; do not describe the
  project as widely used until evidence supports that claim.
